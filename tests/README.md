# Root & System Integration Tests

Real-Time AI/ML-Based Quishing and Smishing Detection & Prevention System.

## Overview
This directory is reserved for end-to-end (E2E), integration, and system verification tests across Android, Backend, AI, and Web Admin components.

- Unit tests for Backend reside in `backend/tests/`
- Unit tests for AI models reside in `ai/tests/`
- Instrumentation & Unit tests for Android reside in `android/app/src/test/` and `android/app/src/androidTest/`
