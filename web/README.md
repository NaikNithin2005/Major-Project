# Web Admin Security Dashboard

Real-Time AI/ML-Based Quishing and Smishing Detection & Prevention System.

## Architecture
- **Framework**: Next.js 14 / React 18 / TypeScript
- **Styling**: Tailwind CSS
- **Authentication**: Firebase Authentication (Admin Role Verification)
- **API Target**: Backend REST endpoints (`/api/v1/admin/*`)

## Phase 0 Foundation Setup

### Local Setup
1. Install Node.js dependencies:
   ```bash
   npm install
   ```
2. Copy environment variables:
   ```bash
   cp .env.example .env.local
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in browser.

### Build Verification
```bash
npm run build
```
